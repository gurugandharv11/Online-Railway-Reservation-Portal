# 🚆 Train Ticket Reservation System

A full-stack Train Ticket Reservation System built using Java, JDBC, Servlets, Oracle SQL, HTML, CSS, and Bootstrap.

This project allows users to search trains, check seat availability, book tickets, manage profiles, and view booking history through a secure web interface.

---

## ✨ Features

### 👤 User Features
- User Registration & Login
- Search Trains
- Check Seat Availability
- Fare Enquiry
- Book Train Tickets
- Payment Gateway
- Booking History
- Profile Management
- Change Password

### 🛠 Admin Features
- Admin Login
- Add Trains
- Update Train Details
- Remove Trains
- Manage Train Schedules
- View All Trains

## ⚙️ Installation Steps

### 1️⃣ Clone Repository

```bash
git clone YOUR_REPOSITORY_LINK
2️⃣ Build Project
mvn clean install
3️⃣ Deploy WAR File

Copy generated WAR file from:

target/TrainBook-1.0.0-SNAPSHOT.war

to Tomcat webapps folder.

4️⃣ Start Tomcat

Run:

startup.bat
5️⃣ Open in Browser
http://localhost:8080/TrainBook-1.0.0-SNAPSHOT
🗄 Database Setup

Create required tables in Oracle SQL and configure database connection properly before running the project.
